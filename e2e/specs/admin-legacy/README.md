# Legacy admin journey contracts

These specs predate the no-stub contract: each is a full intended journey
declared with `test.fixme` until its backing seeds/selectors land. They are
parked here so `specs/admin/**` can enforce zero-fixme (see
specs/admin/no-fixme-guard.spec.ts); un-fixme them by moving them back as
their sprints implement the journeys for real.
