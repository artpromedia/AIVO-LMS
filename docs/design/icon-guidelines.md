# Icon guidelines

Use `lucide-react` for all product icons.

- Canonical icon library: `lucide-react`
- Icon browser: https://lucide.dev/icons
- Sizes:
  - 20px for text-adjacent icons
  - 24px for button icons
  - 32px for hero/emphasis icons
- Color:
  - Icons should inherit color from their parent context by default
  - Avoid hardcoded fills/strokes unless a component requires a specific semantic token

Do **not** add custom inline SVG icons to the codebase unless the asset is a brand mark (logo, mascot, or other approved brand artwork).
