# Parent Export Format

The parent export bundle is generated by `buildParentExport` and
contains three artifacts:

- `learner-<id>.json` — full structured export.
- `learner-<id>.md` — Markdown summary for human readers.
- `learner-<id>-summary.csv` — CSV with section counts.

## Sections

- learner profile summary
- Brain profile summary
- approved accommodations
- recommendation history
- baseline summaries
- lesson progress summaries
- homework summaries
- problem-session summaries
- parent decisions
- teacher observations visible to parent
- audit summary

## Redaction

`stripSensitive` recursively removes the following keys from the
profile and Brain summaries before any artifact is built:

- iepText / rawIepText
- parentPrivateNotes / parentNotes
- medicalNotes / medicalDiagnosis
- freeFormChat / learnerChat
- ocrText / uploadedOcrText
- rawText

Tests lock the "raw IEP text and parent private notes do not appear
in the export" guarantee.
