# Accessibility checklist

- WCAG 2.2 AA baseline across themes
- Sprout mode prioritizes stronger contrast choices
- 2px visible focus outlines with offset
- Keyboard-first semantics for interactive primitives
- Decorative art should be `aria-hidden`
- Mascot assets require descriptive alt text when instructional
- Reduced-motion users receive non-spring transitions
- Status communication always includes text/icon, not color alone
