# STEM Engineering Brain

Drives the `stem_engineering` subject (tutor key `forge` / persona
`ADDON_TUTOR_STEM_DESIGN`).

## Skills

- `STEM.ENG.PROBLEM` — define a problem
- `STEM.ENG.IDEATE` — sketch possible solutions
- `STEM.ENG.BUILD_TEST` — build and test a prototype
- `STEM.ENG.ITERATE` — improve from what we learned

Standards: NGSS engineering design strand (K-2-ETS1 and 3-5-ETS1).

## Model

Process-graded for procedural items: `payload.stepsCompleted /
totalSteps` rather than correctness. Discrete comprehension items
(e.g. "which change is most likely to help?") still use IRT-lite on
correctness.

Adaptation steps the design loop forward when execution is fluent
and drops to comprehension when iteration confidence is low.

## Items

4 fixture items covering one item per design-process step.
