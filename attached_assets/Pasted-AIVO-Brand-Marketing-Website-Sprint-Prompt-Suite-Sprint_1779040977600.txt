Global Rules for Every Marketing Sprint
# Global AIVO Marketing Website Rules

You are building the AIVO Learning marketing website and brand implementation layer for the new AIVO build.

AIVO is an agentic K–12 learning platform that creates personalized learning paths for learners using parent input, optional IEP/accommodation context, baseline assessment, mastery history, and learner-specific LessonRuns.

The marketing website must not feel like a generic AI tutoring landing page.

It must clearly communicate:
- Personalized learning for each child
- Parent-guided setup
- IEP/accommodation-aware support where provided
- Today’s Mission as the learner’s next-best-action
- LessonRun as the core personalized learning unit
- Parent progress clarity
- Teacher and school visibility
- Privacy, safety, accessibility, and trust

Brand constraints:
- Brand name: AIVO Learning
- Wordmark text: AIVO LEARNING
- Do not use “Agentic AI” as the wordmark.
- Use the existing AIVO brain icon unchanged.
- Do not modify the icon shape, stroke, geometry, proportions, or gradient.
- Do not crop the logo or allow the logo to render outside its frame.
- All logo files must support transparent backgrounds.
- Primary brand purple: #7C3AED
- Supporting colors may include:
  - Purple dark: #6D28D9
  - Purple light: #8B5CF6
  - Tech blue: #2563EB
  - Teal: #0891B2
  - Emerald: #059669
  - Navy: #1A1A2E
  - Slate 900: #0F172A
  - Slate 50: #F8FAFC
  - White: #FFFFFF
  - Black: #000000
- Typography: Inter or an Inter-compatible rounded, readable SaaS typography system.
- Use a calm, warm, trustworthy, accessible design language.

Technical assumptions:
- Use Next.js App Router.
- Use TypeScript.
- Use Tailwind CSS.
- Use shadcn-style components where appropriate.
- Use accessible semantic HTML.
- Use production-ready responsive layouts.
- No broken links.
- No dead buttons.
- No fake testimonials.
- No unsupported compliance claims.
- No “SOC 2 certified,” “FERPA compliant,” “COPPA certified,” or similar claims unless the company has the evidence.
- Use “designed for,” “built with,” or “supports” where certification is not yet complete.
- Every form must validate, submit, show success, show error, and prevent duplicate submission.
- Every page must have SEO metadata, Open Graph metadata, and mobile-responsive layout.

Required outputs per sprint:
- Files changed
- Routes created
- Components created
- Copy written
- Data/config created
- Acceptance criteria
- QA checklist
