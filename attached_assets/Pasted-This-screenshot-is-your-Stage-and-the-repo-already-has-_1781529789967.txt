````markdown
# AIVO Learner Experience Design Constitution (prepend to every learner-page prompt)

You are building/elevating AIVO's learner-facing experience in `apps/web-v2` (Next 15, React 19,
Tailwind v4, Radix, pixi.js) and `apps/mobile` (Expo / React Native). The user is a **neurodiverse
K–12 learner**. You are *elevating a real system, not greenfielding* (`learner-experience/
DESIGN-DIRECTION.md`): tokens, theming, sensory plumbing, and engagement data already exist. Build
on `@aivo/stage-ui`, `@aivo/learner-ui`, `@aivo/mobile-ui`, `@aivo/brand` (+ the `--lx-*` learner
token layer). Match the reference Stage screenshot.

North star: a learner should *want to come back tomorrow* — through delight, character, and progress
they can feel, never overload or compulsion. Build "a world with a host," not "a dashboard with
numbers." Bar = Duolingo / Khan Academy Kids, original IP, plus a **Calm mode they don't have**. If
a screen reads as "a dashboard," it isn't done.

Three non-negotiables on every screen:
1. **Neurodiverse-first is load-bearing** — honor My Workspace (Mood, Spacing, Font, Sound) and
   "breaks are good"; every delight element obeys them.
2. **Accessibility never regresses** — WCAG AA contrast (text uses `-ink` token variants; raw chroma
   is decorative-only ≥3:1), full keyboard nav, visible focus, `SkipLink`, `LiveRegion` SR
   announcements. A playful palette is no excuse for low contrast.
3. **No dark patterns** — grace on streaks; no FOMO, shame, countdowns, or loot-box mechanics.

Mandatory behaviors:
- **One primary action per screen** (`PrimarySlot`); progressive disclosure.
- **Audio-first** — read-aloud / Play-sound always present; TTS via the contract (6 voices, speed
  0.5–1.5).
- **Functioning-level adaptation** (`FlVariantProvider`, `FL_PROFILES`) — density + choice count
  scale from STANDARD (full, ≤5) to PRE_SYMBOLIC (single, ≤2); never exceed the learner's
  `maxChoices`.
- **Sensory + Mood** — `data-sensory-mode` (standard/calm/high-contrast → motionScale 1/0.5/0) and
  Mood (Calm/Balanced/Energizing → `--lx-motion` 0.45/1/1.2). Calm genuinely turns the dial down;
  keep contrast a separate toggle (don't let "Energizing" kill motion). Respect
  `prefers-reduced-motion`; PRE_SYMBOLIC = no motion.
- **AAC + switch access** — touch/switch/eye-gaze/head-pointer with scan/dwell timing
  (`@aivo/accessibility-contract`, `@aivo/aac-bridge`, mobile SwitchScanOverlay); every custom
  gesture has a one-tap alternative.
- **Breaks** — a calm, non-punitive break affordance (`BreakCloud`) per the learner's break
  interval; never gate or shame.
- **Age tiers** (`TIER_THEMES` / `gradeToTier`) — dignified for older kids, gentle for younger.
- **Theming** via `data-*` attributes + `@aivo/brand` tokens + `--lx-*`; no raw hex; never fork the
  pipeline. Web (CSS/Tailwind) and mobile (RN) render from the same contract.
- **Original IP** — host/mascot + tutor characters are expressive but obey every sensory setting;
  upgrade the crude placeholder art.

For each page: don't jump to code. First return (a) the screen-state map (incl. empty/loading/error/
celebration and the PRE_SYMBOLIC variant), (b) the interaction + audio/AAC spec, (c) the visual
direction in tokens. Preview in `app/design-system/*` (dev-only). Pause for approval.
````
