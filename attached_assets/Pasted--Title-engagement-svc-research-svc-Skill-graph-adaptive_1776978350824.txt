## Title
[engagement-svc + research-svc] Skill graph, adaptive scenarios, gamification, efficacy telemetry

## Context
Turn the buddy from a toy into a measurable learning program.

## Tasks
1. **Skill graph + mastery model** in `engagement-svc`:
   - Bayesian knowledge-tracing or simple Elo-per-skill: each turn contributes evidence via `scoreTurn` rubric (engagement, turn-taking, empathy tokens, question quality).
   - `GET /speech-buddy/learners/:id/skill-profile` returns normalized mastery per micro-skill.
2. **Adaptive scenario selection**: planner in `ai-svc` consumes the skill profile to pick the next scenario, prioritizing skills just below mastery threshold and rotating to avoid fatigue.
3. **Gamification**: streaks, collectible "friendship tokens" per skill, weekly quests, parent-visible-only celebration. No external leaderboards. No dark patterns; explicit cap of 1 meaningful session/day for age 6–9, 2/day for 10–12, 3/day for 13–15 (configurable).
4. **Research + efficacy** in `research-svc`:
   - Opt-in, de-identified dataset: pre/post mini self-report (age-appropriate Likert with emojis), skill-mastery trajectories, session counts.
   - Weekly aggregated report artifact for the pilot team; IRB-style data-handling doc `docs/products/speech-buddy/research-ethics.md`.
5. **Pilot hooks**: if a user has an active `PilotEntitlement` (from Feature 1), Speech Buddy is automatically enabled for eligible age bands; expiry gracefully transitions to a free-tier "lite" mode (one scenario/day, no voice — text only).

## Acceptance criteria
- Adaptive selection demonstrably shifts scenario distribution after 5 sessions in a simulation harness.
- Daily caps enforced server-side, not just UI.
- Weekly research report generated automatically and downloadable by platform admins.
- End-to-end pilot scenario passes: admin issues 60-day coupon → parent consents → child runs 10 sessions over 2 weeks → skill profile updates → parent weekly email received → research report shows cohort trend.
